.. _visualizations:

Visualizations
==============

Explore how query strategies select samples across active learning cycles.
Each animation uses a small synthetic dataset. Open its card to see the
accompanying explanation and code.
Choose pool-based or stream-based active learning, then classification or
regression. Within classification, separate groups explain the animation
layouts for target types, annotators, and acquisition batches. A strategy
may support additional setups: use the
:doc:`Strategy Overview </generated/strategy_overview>` to filter methods by
their supported setups. Cards describe the acquisition rule and count used
in each pool example and are ordered alphabetically by example title.
